🗣️ Command words
  • Define – give the meaning of a word.
  • State – a short answer. No reason needed.
  • Identify – pick out or name something.
  • Complete – fill in the gaps.
  • Explain – say why. Use the word “because”.
  • Describe – say what happens, step by step.
  • Write – create your own answer from scratch.
🔷 Flowchart shapes key

The flowcharts on this page use these colours:

START Oval = start / end

▭ Rectangle = process

▱ Parallelogram = input / output

◆ Diamond = decision (YES / NO)

📋 How to trace
  1. Start at START. Follow the arrows.
  2. Write down each variable’s value as it changes.
  3. At a diamond, check the condition carefully. Is it < or <=?
  4. Write down every output in order.
🐛 Bug-hunting questions

Ask yourself:

  • Does every path reach END?
  • Does the variable in a loop ever change?
  • Is the condition right for the boundary value?
  • Is the right shape used for each step?
✍️ Writing structured English
  • Number your steps: 1, 2, 3…
  • One action per line.
  • Keywords: IF … THEN … ELSE … ENDIF
  • Loops: WHILE … ENDWHILE
